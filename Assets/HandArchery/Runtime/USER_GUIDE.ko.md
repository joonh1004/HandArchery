# 손으로 하는 양궁 체험

`HandArchery.exe`와 `HandArchery_Data`, `UnityPlayer.dll`, 나머지 실행 파일을 **같은 폴더에 둔 채** 실행합니다. exe 하나만 따로 옮기면 실행되지 않습니다. 인터넷 계정이나 로그인은 필요하지 않습니다. 이 버전은 Windows 웹캠과 양손을 사용합니다.

1. 밝은 곳에서 카메라에 양손이 들어오도록 앉거나 섭니다. 다른 앱이 카메라를 사용 중이면 닫아 주세요.
2. `체험 시작`을 누르고 양손을 펼쳐 잠깐 기다립니다. 기본은 왼손이 활손, 오른손이 시위손입니다.
3. 왼손 위치로 조준점을 옮깁니다. 오른 엄지·검지를 붙여 시위를 잡고 두 손 사이가 **옆으로** 벌어지도록 오른손을 움직입니다. 화면에 표시되는 당김 힘을 확인합니다.
4. 오른 엄지·검지를 벌리면 한 발이 나갑니다. 화살이 과녁에 도달하면 점수가 표시됩니다. 다음 발은 양손을 펼쳐 다시 준비합니다.
5. 다섯 발의 결과를 확인하고 `한 번 더 도전` 또는 `다시 하기`로 새 라운드를 시작합니다.

가운데는 10점, 바깥쪽은 1점이며 과녁 밖은 0점입니다. 몸의 자세나 실제 활의 장력을 측정하는 운동 훈련 장치는 아닙니다.

손이 가려지거나 입력이 오래되면 당김이 취소됩니다. 양손을 다시 보여 주고 펼쳐 준비하세요. 다른 창으로 이동해도 당김이 취소됩니다. 창으로 돌아오면 다시 준비하세요. 이미 날아간 화살의 결과는 계속 처리됩니다.

화면의 `입력 재시작`은 카메라 연결을 다시 시도합니다. 점수가 지워지는 기능은 아닙니다. 손의 좌우가 다르게 인식되면 `좌우손` 옵션을, 화면 이동 방향이 어색하면 `거울` 옵션을 점검하세요. 각 옵션을 바꾸면 손을 다시 펼쳐야 합니다. `활을 잡는 손`으로 오른손 활을 선택할 수 있습니다. 화면 아래 안내도 함께 바뀝니다.

문제를 점검할 때만 `입력 진단 보기`를 누르면 별도 패널에서 기술 상태와 손 좌표를 볼 수 있습니다. 패널의 `닫기` 또는 `입력 진단 닫기`로 숨길 수 있습니다. 평소에는 화면 위의 한국어 인식 안내를 따라 주세요.

기본 모드는 실제 카메라입니다. 입력 오류 때 마우스로 자동 전환하지 않습니다. 카메라 영상은 화면에 보여 주거나 저장·전송하지 않습니다. 좌표와 인식 상태만 사용합니다. Windows 카메라 권한과 실제 시연 기기의 손 인식 품질은 별도로 확인해야 합니다.

개발자가 `--handarchery-smoke` 옵션으로 실행하면 카메라 없이 **합성 검사 입력**을 사용하며 화면 상단에 그 사실이 계속 표시됩니다. 합성 검사 통과는 실제 손 입력 합격을 뜻하지 않습니다.
