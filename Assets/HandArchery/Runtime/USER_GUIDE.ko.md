# 손으로 하는 양궁 체험

`HandArchery.exe`와 `HandArchery_Data`, `UnityPlayer.dll`, 나머지 실행 파일을 **같은 폴더에 둔 채** 실행합니다. exe 하나만 따로 옮기면 실행되지 않습니다. 인터넷 계정이나 로그인은 필요하지 않습니다. 이 버전은 Windows 웹캠과 양손을 사용합니다.

1. 밝은 곳에서 카메라에 양손이 들어오도록 앉거나 섭니다. 다른 앱이 카메라를 사용 중이면 닫아 주세요.
2. `체험 시작`을 누르고 양손을 펼쳐 잠깐 기다립니다. 기본은 왼손이 활손, 오른손이 시위손입니다.
3. 왼손 위치로 조준점을 옮깁니다. 오른 엄지·검지를 붙여 시위를 잡고 두 손 사이가 **옆으로** 벌어지도록 오른손을 움직입니다. 화면에 표시되는 당김 힘을 확인합니다.
4. 오른 엄지·검지를 벌리면 한 발이 나갑니다. 화살이 과녁에 도달하면 점수가 표시됩니다. 다음 발은 양손을 펼쳐 다시 준비합니다.
5. 다섯 발의 결과를 확인하고 `한 번 더 도전` 또는 `다시 하기`로 새 라운드를 시작합니다.

가운데는 10점, 바깥쪽은 1점이며 과녁 밖은 0점입니다. 몸의 자세나 실제 활의 장력을 측정하는 운동 훈련 장치는 아닙니다.

손이 가려지거나 입력이 오래되면 당김이 취소됩니다. 카메라가 계속 켜져 있다면 `입력 재시작`을 누를 필요 없이 양손을 다시 보여 주고 펼친 채 잠깐 기다리면 자동으로 준비됩니다. 점수와 남은 화살은 유지됩니다. 다른 창으로 이동해도 당김이 취소됩니다. 창으로 돌아오면 다시 준비하세요. 이미 날아간 화살의 결과는 계속 처리됩니다.

화면의 `입력 재시작`은 영상까지 멈추거나 카메라 연결에 문제가 있을 때 다시 시도하는 버튼입니다. 점수가 지워지는 기능은 아닙니다. 손의 좌우가 다르게 인식되면 `좌우손` 옵션을, 화면 이동 방향이 어색하면 `거울` 옵션을 점검하세요. 각 옵션을 바꾸면 손을 다시 펼쳐야 합니다. 시작할 때 활손은 왼손입니다. `활손: 왼손 → 오른손 전환`을 누르면 오른손 활로, 다시 누르면 왼손 활로 바뀝니다. 활손 선택은 인식 좌우 라벨 보정과 거울 설정과 별개입니다.

조준경은 밝은 청록색과 검정 윤곽으로 표시합니다. 시위를 당길수록 화면이 아주 약하게 부드럽게 확대되고, 발사·당김 취소·손 소실·포커스 이동·라운드 종료 시 원래 크기로 돌아옵니다. 조준 위치와 화살의 궤적 계산은 바뀌지 않습니다.

왼쪽 아래 작은 카메라 화면에서 내 모습과 양손이 모두 들어오는지 확인하세요. 기존 3단계 안내 패널을 이 미리보기로 바꿨습니다. 영상 비율을 유지하고, `거울` 설정을 조준 좌표와 함께 적용합니다. 카메라가 없거나 준비·중단 상태이면 영상 대신 검은 화면과 상태를 표시합니다. 입력이 멈추면 이전 영상을 실시간 화면처럼 남겨 두지 않습니다.

문제를 점검할 때만 `입력 진단 보기`를 누르면 별도 패널에서 기술 상태와 손 좌표를 볼 수 있습니다. 패널의 `닫기` 또는 `입력 진단 닫기`로 숨길 수 있습니다. 평소에는 화면 위의 한국어 인식 안내를 따라 주세요.

기본 모드는 실제 카메라입니다. 입력 오류 때 마우스로 자동 전환하지 않습니다. 카메라 영상은 이 컴퓨터의 실시간 손 인식과 미리보기에만 사용하며 저장·전송하지 않습니다. Windows 카메라 권한과 실제 시연 기기의 손 인식 품질은 별도로 확인해야 합니다.

개발자가 `--handarchery-smoke` 옵션으로 실행하면 카메라 없이 **합성 검사 입력**을 사용하며 화면 상단에 그 사실이 계속 표시됩니다. 왼쪽 아래에도 `합성 검사 모드 · 카메라 미리보기 없음`이라고 표시합니다. 합성 검사 통과는 실제 손 입력 합격을 뜻하지 않습니다.
